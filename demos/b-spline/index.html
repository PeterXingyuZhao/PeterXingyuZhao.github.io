B-Spline Explorer

Explore how degree, control points, and knot vectors shape a B-spline curve. The demo calculates blending functions symbolically with the Cox–de Boor recursion, represents coefficients as fractions, and displays the resulting piecewise formulas and graphs.

Move control points, edit the knots, and highlight a parameter value to see which control points and basis functions contribute locally.
